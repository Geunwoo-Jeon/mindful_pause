개인정보 처리방침

최종 업데이트: 2025년 1월 26일

🔒 핵심 요약
"잠시, 멈춤" 앱은 어떠한 개인정보도 수집하거나 외부로 전송하지 않습니다.
모든 데이터는 사용자의 기기에만 저장되며, 서버나 제3자와 공유되지 않습니다.

1. 개인정보의 수집 및 이용

1.1 수집하는 정보

본 앱은 다음 정보를 사용자의 기기에만 저장합니다:

  • 목표 정보: 사용자가 입력한 5년/1년/3개월 목표
  • 답변 기록: 자기 성찰 질문에 대한 답변 내용 및 작성 시간
  • 앱 설정: 리마인드 간격, 일시중지 설정 등

1.2 데이터 저장 방식

모든 데이터는 Android의 Room Database를 사용하여 사용자의 기기 내부에만 저장됩니다.

  • ✅ 기기 내부 저장소에만 보관
  • ✅ 서버 전송 없음
  • ✅ 클라우드 동기화 없음
  • ✅ 제3자 공유 없음

2. 앱 권한 사용 목적

본 앱은 기능 제공을 위해 다음 권한을 요청합니다:

2.1 필수 권한

  • 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW): 자기 성찰 질문 팝업을 표시하기 위해 사용
  • 알림 (POST_NOTIFICATIONS): 백그라운드 서비스 실행 상태를 알리기 위해 사용
  • 접근성 서비스 (AccessibilityService): 앱 사용을 감지하여 적절한 시점에 질문을 표시하기 위해 사용. 사용자가 입력하는 텍스트나 개인정보는 수집하지 않으며, 오직 앱 전환 이벤트만 감지합니다.
  • 사용 통계 (PACKAGE_USAGE_STATS): 오늘의 스크린타임을 표시하기 위해 사용. 통계는 기기에서만 계산되며 외부로 전송되지 않습니다.

2.2 선택적 권한

  • 부팅 시 자동 시작 (RECEIVE_BOOT_COMPLETED): 기기 재시작 후 서비스를 자동으로 재시작하기 위해 사용 (사용자가 비활성화 가능)

3. 개인정보의 제3자 제공

본 앱은 어떠한 개인정보도 제3자에게 제공하지 않습니다.

  • ❌ 광고 플랫폼 사용 안 함
  • ❌ 분석 도구 사용 안 함 (Google Analytics 등)
  • ❌ 서버 연결 없음
  • ❌ 소셜 미디어 연동 없음

4. 개인정보의 보유 및 삭제

4.1 보유 기간

모든 데이터는 사용자가 앱을 삭제할 때까지 기기에 보관됩니다.

4.2 삭제 방법

다음 방법으로 데이터를 완전히 삭제할 수 있습니다:

  • 방법 1: 앱 삭제 (기기 설정 > 앱 > 잠시, 멈춤 > 삭제)
  • 방법 2: 앱 데이터 삭제 (기기 설정 > 앱 > 잠시, 멈춤 > 저장공간 > 데이터 삭제)

5. 아동의 개인정보 보호

본 앱은 13세 미만 아동을 대상으로 하지 않으며, 13세 미만 아동으로부터 고의로 정보를 수집하지 않습니다. 만약 13세 미만 아동의 정보가 수집되었음을 발견한 경우, 즉시 해당 정보를 삭제하겠습니다.

6. 개인정보 처리방침의 변경

본 개인정보 처리방침은 법령, 정책 또는 앱 기능의 변경에 따라 수정될 수 있습니다. 중요한 변경사항이 있을 경우 앱 업데이트 노트를 통해 공지합니다.
