Политика Конфиденциальности

Последнее обновление: 26 января 2025 г.

🔒 Основные Моменты
Приложение "Пауза, Размышление" не собирает и не передает никакую личную информацию во внешние источники.
Все данные хранятся только на вашем устройстве и никогда не передаются на серверы или третьим лицам.

1. Сбор и Использование Информации

Это приложение хранит следующую информацию только на вашем устройстве:

  • Цели: Ваши 5-летние, 1-летние и 3-месячные цели
  • Записи ответов: Ваши ответы на вопросы самоанализа и временные метки
  • Настройки приложения: Интервал напоминаний, настройки паузы и т.д.

Все данные хранятся с использованием Room Database Android исключительно на вашем устройстве.

  • ✅ Хранится только во внутренней памяти устройства
  • ✅ Нет передачи на сервер
  • ✅ Нет облачной синхронизации
  • ✅ Нет обмена с третьими лицами

2. Разрешения Приложения

  • Отображение поверх других приложений: Для отображения всплывающих окон с вопросами самоанализа
  • Уведомления: Для отображения уведомлений о состоянии фонового сервиса
  • Служба специальных возможностей: Для обнаружения использования приложений. Не собирает текстовый ввод или личную информацию.
  • Статистика использования: Для отображения сегодняшнего экранного времени. Рассчитывается только на устройстве.

3. Обмен с Третьими Лицами

Это приложение не передает никакую личную информацию третьим лицам.

  • ❌ Нет рекламных платформ
  • ❌ Нет инструментов аналитики
  • ❌ Нет подключений к серверу
  • ❌ Нет интеграций с социальными сетями

4. Хранение и Удаление Данных

Все данные хранятся на вашем устройстве до удаления приложения.

Методы удаления:

  • Метод 1: Удалите приложение
  • Метод 2: Очистите данные приложения (Настройки > Приложения > Пауза, Размышление > Хранилище > Очистить Данные)
